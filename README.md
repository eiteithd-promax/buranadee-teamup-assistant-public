# BURANADEE Teamup Assistant — Public Edition

Public version of BURANADEE Teamup Assistant for general Teamup users.

## Live app

https://buranadee-teamup-assistant-public-edition-ak8z1w.v2.appdeploy.ai/

## Main features

- Thai Quick Input → English Teamup event titles
- Auto category and color workflow
- 12:00–13:00 lunch protection
- User-owned Teamup connection and 5-category mapping
- Monthly Calendar sync
- Attendance OCR + Auto-Time workflow
- PDF Export, Queue and Merge
- Built-in Guide and FAQ
- Responsive desktop and mobile UI

## Public credential model

This edition does **not** use BURANADEE's internal Teamup credentials. Each user connects their own Teamup API key and calendar link/key. The app lets the user decide whether the connection should be remembered on the current device.
